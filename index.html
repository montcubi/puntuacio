Guia

Primer ús (2 minuts)

  • Tria la classe al selector de dalt.
  • Afegeix alumnes (camp "Afegir alumne...") o usa Importar.
  • Suma/resta punts amb els botons de cada alumne.
  • Desa una còpia: Configuració → Descarregar.

Classes

  • Crear/renombrar/eliminar: botó del llapis al costat del selector de classe.
  • Les dades es guarden per classe (alumnes, objectiu, etc.).

Alumnes i assistència

  • Afegir: escriu el nom i prem +.
  • Importar: un nom per línia (ideal per enganxar des d'un document).
  • Cercar: usa el camp "Cercar..." per filtrar.
  • Absent: el commutador marca l'alumne com absent (i bloqueja els botons de punts).
  • Eliminar: botó paperera (o "Eliminar alumne" en mòbil).

IDs (per projecció)

  • Botó IDs: mostra el llistat i permet copiar-lo.
  • Regenerar canvia tots els codis: fes backup abans.

Ítems (botons de punts)

  • Botó Ítems: crea, edita o elimina botons.
  • Defineix nom, punts (positius o negatius), color i icona.

Objectiu del trimestre

  • A la capçalera veuràs l'Objectiu (0 per defecte).
  • + suma punts a l'objectiu; la paperera el reinicia.
  • Quan l'objectiu és > 0, el marcador mostra punts / objectiu.

Mode projecció

  • Botó Projectar: mostra els resultats anònims per ID.
  • Útil per donar feedback sense mostrar noms a pantalla.

Exportar i no perdre dades

  • CSV: exporta la classe actual per obrir a Excel/Sheets.
  • Backup: Configuració → Descarregar/Restaurar per moure dades entre ordinadors.
  • Si el navegador ho permet, el backup et deixa triar carpeta (ideal: carpeta sincronitzada).

Privacitat i consells

  • Les dades es guarden al navegador (localStorage). Si esborres dades del navegador, es perden.
  • Fes backup regularment (per exemple, setmanal o al final de la sessió).
  • Obre l'app amb un servidor local (ex: python3 -m http.server) per evitar limitacions de file://.
